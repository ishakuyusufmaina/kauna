Migrate students: working copy → master records

For every class in the chosen session this reads {school}/{session}/{class}/students and creates a master record at {school}/db/students/{id} in the format admin/class.html uses. Students whose id is missing or is a temporary one (e.g. std3) are issued a real id (yy/yy/term/number) and re-keyed in the working copy, exactly as class.html does. Classes are processed one at a time, each in its own batch, and finished classes are remembered in this browser so an interrupted run carries on where it stopped. Existing master records are never overwritten, so the page is safe to run again. Do not use the class, students or score-sheet pages while it runs.
